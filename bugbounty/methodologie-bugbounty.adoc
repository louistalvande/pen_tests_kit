== 3. Reconnaissance passive

* [ ] Whois / informations d'enregistrement
* [ ] Certificate Transparency (crt.sh, censys)
* [ ] Énumération de sous-domaines (subfinder, amass, assetfinder)
* [ ] Google dorking
* [ ] Recherche GitHub / GitLab (secrets, repos liés)
* [ ] Shodan / Censys (services exposés)
* [ ] Wayback Machine / archive.org
* [ ] Offres d'emploi / réseaux sociaux (stack technique)

TIP: Ajouter les résultats de chaque point directement sous la case correspondante.

== 4. Reconnaissance active

* [ ] Résolution DNS des sous-domaines (httpx, dnsx)
* [ ] Scan de ports (nmap, masscan)
* [ ] Fingerprinting technologique (Wappalyzer, whatweb)
* [ ] Screenshots de masse (aquatone, gowitness)
* [ ] Crawl du site (Burp Spider, katana)
* [ ] Découverte de contenu caché (ffuf, gobuster, dirsearch)
* [ ] Fichiers sensibles (.git, .env, sauvegardes)
* [ ] Découverte d'API (Swagger/OpenAPI, introspection GraphQL)
